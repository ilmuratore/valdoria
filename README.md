# Valdoria

![Unity](https://img.shields.io/badge/Unity-6.3_LTS-000000?style=flat-square&logo=unity)
![C#](https://img.shields.io/badge/C%23-239120?style=flat-square)
![Status](https://img.shields.io/badge/Status-In_Development-orange?style=flat-square)

**Valdoria** è un progetto videoludico RPG 2D con visuale top-down, sviluppato in Unity e C#, orientato alla sperimentazione delle principali meccaniche di gameplay e dei principi della programmazione orientata agli oggetti.

## Funzionalità

- Movimento e animazioni del personaggio.
- Sistema di combattimento, bersagli, danni e gestione della vita e della morte.
- NPC alleati e nemici con intelligenza artificiale basata su una macchina a stati (FSM).
- Pattugliamento, inseguimento, ricerca e attacco degli NPC.
- Sistema di esperienza e progressione del personaggio.
- Gestione dei livelli della mappa e delle scale.
- Interfaccia utente per salute e progressione.

## Tecnologie

- Unity 6.3 LTS (6000.3.28f1)
- C#
- Universal Render Pipeline (URP 2D)
- Unity Input System
- TextMesh Pro

## Avvio del progetto

1. Clonare il repository:

   ```bash
   git clone https://github.com/ilmuratore/valdoria.git
   ```

2. Aprire la cartella `valdoria` tramite Unity Hub utilizzando la versione di Unity indicata.
3. Aprire una scena dalla cartella `Assets/Scenes`.
4. Premere **Play** nell'editor.

## Stato del progetto

Il progetto è attualmente in sviluppo. Le meccaniche di gioco e i sistemi esistenti sono soggetti a miglioramenti ed estensioni.
